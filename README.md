# Signo-php
 
# 🔮 Consulta de Signo Zodiacal - Projeto em PHP + XML

Este projeto é uma aplicação web simples desenvolvida em PHP que permite ao usuário descobrir seu signo do zodíaco com base na data de nascimento. O resultado é exibido após a leitura de um arquivo XML com as informações de cada signo.

---

## 📁 Estrutura do Projeto

```
Project/
├── assets/
│   ├── css/
│   │   └── style.css
├── layouts/
│   └── header.php
├── index.php
├── show_zodiac_sign.php
└── signos.xml
```

---

## ✅ Funcionalidades

* Formulário para inserção da data de nascimento
* Leitura dinâmica de dados a partir de um arquivo XML
* Exibição personalizada do signo zodiacal
* Layout responsivo com Bootstrap

## ▶️ Como Rodar o Projeto Localmente

### 1. Requisitos

* [Visual Studio Code](https://code.visualstudio.com/)
* [XAMPP (Apache)](https://www.apachefriends.org/pt_br/index.html)

---

### 2. Passo a Passo

1. **Clone o repositório ou baixe o ZIP**

   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```

2. **Copie a pasta do projeto para o diretório do XAMPP:**

   * Caminho padrão:

     ```
     C:\xampp\htdocs\
     ```
   * Exemplo:

     ```
     C:\xampp\htdocs\Project\
     ```

3. **Inicie o Apache no XAMPP:**

   * Abra o XAMPP Control Panel
   * Clique em “Start” ao lado de **Apache**

4. **Abra o projeto no VS Code:**

   * `File > Open Folder` e selecione a pasta `Project` dentro de `htdocs`

5. **Acesse no navegador:**

   ```
   http://localhost/Project
   ```
